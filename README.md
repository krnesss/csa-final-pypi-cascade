# 一个底层包的漏洞，怎样级联到整个生态？

> **复杂系统分析 · 期末项目** · 选题 Q4
> PyPI 依赖网络中的影响传播、瓶颈识别与韧性情景实验
> 数据快照：**2026-11** ｜ 15,718 个包 ｜ 47,273 条依赖边 ｜ 26,810 条安全公告

---

## 三条结论（先看这个）

| 数字 | 含义 |
|---|---|
| **95.7×** | 朴素"结构依赖扫描"对真实风险的高估倍数（1,314,448 对 vs 13,730 对）。**98.9% 的高估来自"依赖者早已升级越过修复版本"** |
| **41.7 pp** | 如果把食物网的"或门"级联规则搬到软件（软件是"与门"），韧性会被高估的百分点数 |
| **38–57&times;** | 把"谁连谁"随机化但**保持度序列**后，平均级联规模的暴涨倍数 ⇒ 保护生态的是**分层结构**，不是度分布 |

**对一个底层包漏洞的定量回答**：平均波及 **11.29** 个种子包（图口径 11.07），最坏 **4,655** 个（`typing-extensions` = 全生态 31%），
最深 **20** 跳；前 0.5% 的 78 个包承担 **52.1%** 的潜在波及量。

## 一键复现

```powershell
cd project
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1             # 全流程（含约 17 分钟 API 抓取）
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1 -SkipFetch  # 数据已就位，只重跑分析（约 2 分钟）
python -X utf8 src/40_make_pptx.py                                           # 单独重新生成 PPT
```

> 脚本内部固定 `PYTHONHASHSEED=0`。原因见 `report/02_数据与方法.md` §5.2：
> 零模型的边随机化从一个 `set` 起步，不固定哈希种子会让同一 seed 在不同进程间
> 相差约 0.02%。固定后**端到端重跑逐位一致**。

**环境**：Python 3.13 + `networkx pandas numpy scipy matplotlib packaging pyarrow pyyaml python-pptx pillow`

**数据来源**（全部公开、无需密钥、无需登录）：
* PyPI 月下载量榜：`hugovk.github.io/top-pypi-packages`（镜像 pypistats 的 ClickHouse 统计）
* 依赖图：`api.deps.dev/v3`（Google osv-scanner 团队）—— 返回**已解析**依赖闭包
* 漏洞库：`osv-vulnerabilities.storage.googleapis.com/PyPI/all.zip`

## 关键口径（读结果前必看）

| 口径 | 定义 | 用在哪 |
|---|---|---|
| **依赖流方向** | 边 `u → v` 表示 **u 依赖 v** | 建图 |
| **级联传播方向** | 与依赖流**相反**：v 出问题 → 传播到所有**传递依赖 v** 的包 | 所有影响面指标 |
| **闭包口径（精确）** | 用 deps.dev 的已解析闭包统计"被多少种子包传递依赖" | `n_transitive_dependents`，主口径 |
| **图口径** | 直接边图上的反向可达集 | `n_transitive_all_nodes`，与闭包口径 ρ=0.971 互校 |
| **R_AND（软件真实）** | 任一直接依赖坏 ⇒ 包坏 | 韧性实验主口径 |
| **R_OR（食物网）** | 全部直接依赖坏 ⇒ 包坏 | 韧性实验对照 |
| **三级漏洞口径** | S 结构上界 / F 反事实未修复 / V 现实版本感知 | 实验三 |
| **PageRank 方向** | `pagerank_importance` 算在依赖流图上（"被谁依赖"）；`pagerank_inherited` 算在反向图（"依赖了谁"）。**两者 ρ = −0.065，几乎正交，方向搞反结论反掉** | 指标一致性 |

## 三条必须写在结论旁边的限定

1. **没做方法级可达性分析**。版本脆弱 ≠ 代码真的调用了脆弱函数。所有"影响面"都是**上界**。
2. **现实口径衡量的是"今天全新解析（fresh install）"**，不是"所有已部署环境"。
   大量用户 pin 在旧版本，那部分存量风险不在该口径内。
3. **拓扑指标的预测力只有 ρ ≈ 0.4**，且随时间距离单调上升（0.37 → 0.49）。
   它不是"漏洞风险预测器"，而是"仍然活着的风险的排序器"。
